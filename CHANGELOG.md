# Change Log

All notable changes to this project will be documented in this file.
See [Conventional Commits](https://conventionalcommits.org) for commit guidelines.

## 0.1.0

 - **FEAT**: initial Dart-only release of `zk_jwt`.
 - **FEAT**: Poseidon hashing via prebuilt `affinidi-zkp-crypto-rs` binaries and
   Dart native-asset build hooks (no Rust required on consumer machines).
 - **FEAT**: issuer, holder, and verifier flows for Selective Disclosure JWTs
   with the ZK-friendly `poseidon-v1` digest algorithm.
